# 實際 Demo 截圖

這五張由零金鑰 Replay 模式的真實頁面擷取，解析度 1440 × 1000。
使用固定 seed 假資料；沒有攔截／替換 API 回應，沒有修改 DOM 內容，沒有叫模型假裝作答。
客人姓名已遮罩，電話只留後四碼；截圖不含瀏覽器分頁、書籤或其他桌面內容。

`README.md` 第 2 節引用的檔名如下，加圖時請沿用，不要另外取名：

| 檔名 | 要拍到什麼 |
|---|---|
| `home-chat.png` | 首頁聊天：左邊導覽、六顆快捷鈕、右上角資料來源徽章 |
| `tool-trace.png` | 一個答案下方攤開的兩輪工具軌跡：工具名、實際參數、幾筆 |
| `masked-list.png` | 客人清單：姓名是 `王○明` 這種形狀、電話只有後四碼 |
| `empty-answer.png` | 客人頁搜尋 `NO_MATCH_DEMO` 的空結果；不是模型問答，沒有補出客人 |
| `mode-badge.png` | 按下徽章想切到 PRODUCTION 時的 400（公開版沒有正式 provider） |

## 拍之前

- 用**零金鑰 Replay 模式**跑（`README.md` 第 4 節 (a)），資料才會跟影片與考卷答案一致：
  示範資料的「現在」釘在 `2026-09-01T00:00:00+08:00`。
- 視窗寬度用 1440px 上下，側邊欄與工具軌跡都塞得下。
- 拍完檢查一遍：畫面上**不准出現**未遮罩的姓名、完整電話號碼、
  任何真實店名或金鑰。示範資料本身是假的，但瀏覽器的分頁、書籤列、
  終端機視窗常常會把不該入鏡的東西一起帶進來。
- PNG，不要截整個螢幕；單張控制在 500 KB 以內。
