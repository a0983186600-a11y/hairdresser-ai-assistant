# 實際 Demo 截圖

這五張由零金鑰 Replay 模式的真實頁面擷取，手機尺寸 452 × 900。
使用固定 seed 假資料；沒有攔截／替換 API 回應，沒有修改 DOM 內容，沒有叫模型假裝作答。
客人姓名已遮罩，電話只留後四碼；截圖不含瀏覽器分頁、書籤或其他桌面內容。

畫面是**一個手機殼**：首頁就是對話，預約、班表、客人、設定都從同一頁以疊層
視窗（sheet）打開，不是四個獨立網址。所以每一張截圖的底層都會看到同一個首頁。

`README.md` 第 2 節引用的檔名如下，加圖時請沿用，不要另外取名：

| 檔名 | 拍到什麼 |
|---|---|
| `home-chat.png` | 首頁：資料來源徽章「DEMO · 示範」、四顆分頁鈕、助理招呼語、三顆捷徑與六顆快捷問法、底部輸入列 |
| `tool-trace.png` | 一題的完整過程：問句、「用了哪些工具（2）」下面兩張工具卡（工具名、實際參數、幾筆），再下面才是答案 |
| `masked-list.png` | 客人清單疊層：姓名是 `高○湘` 這種形狀、電話只有後四碼 |
| `empty-answer.png` | 客人頁搜尋「沒有這位示範客人」的空結果：只說「沒有符合的客人。」，不補人；不是模型問答 |
| `mode-badge.png` | 按徽章想切到正式資料時的回絕吐司：「沒有設定 PRODUCTION_READ_URL，這一份只跑得動示範資料」，徽章仍是「DEMO · 示範」 |

## 拍之前

- 用**零金鑰 Replay 模式**跑（`README.md` 第 4 節 (a)），資料才會跟影片與考卷答案一致：
  示範資料的「現在」釘在 `2026-09-01T00:00:00+08:00`。
- 視窗用 452 × 900（手機殼在這個寬度剛好滿版，工具卡也不會被切掉）。
- `tool-trace.png` 要等工具卡全部翻成「查完了」、答案也出來了再拍。卡片是一張一張
  出現的，拍太早會只拍到「正在查…」。
- 拍完檢查一遍：畫面上**不准出現**未遮罩的姓名、完整電話號碼、
  任何真實店名或金鑰。示範資料本身是假的，但瀏覽器的分頁、書籤列、
  終端機視窗常常會把不該入鏡的東西一起帶進來。
- PNG，不要截整個螢幕；單張控制在 500 KB 以內。
